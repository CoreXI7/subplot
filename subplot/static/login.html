Sign in to Subplot.

Create the account that signs in to this page. You need the setup code printed on the server by:

sudo runuser -u RUN_USER -- env SUBS_STATE=STATE_DIR python3 -I CODE_DIR/subplot/auth.py setup-code

Each run prints a new code; only the newest one works, and creating the account uses it up.

At least 15 characters. A few random words are easy to remember and hard to guess.

Type the 6-digit code from your authenticator app, or one of your recovery codes.

This page is not using HTTPS, so signing in is turned off. Open Subplot through the https address your reverse proxy provides, with X-Forwarded-Proto: https.

The sign-in file is damaged, so nobody can sign in. On the server, run sudo runuser -u RUN_USER -- env SUBS_STATE=STATE_DIR python3 -I CODE_DIR/subplot/auth.py reset; it prints a new setup code.
